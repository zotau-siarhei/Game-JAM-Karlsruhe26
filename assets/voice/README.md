# Реплики штаба

Здесь лежат заранее озвученные реплики и их список.

- `lines.json` — список реплик. Его читают и игра, и страница предпросмотра.
- `*.mp3` — звуковые файлы реплик, имена берутся из поля `file`.
- `preview.html` — таблица реплик с кнопкой прослушивания.

## Формат `lines.json`

```json
{
  "lines": [
    { "id": "run_start", "event": "Старт забега", "text": "Текст реплики", "file": "run_start.mp3" }
  ]
}
```

- `id` — идентификатор, по которому реплику вызывает код игры. Обязателен и не повторяется.
- `event` — описание события, на которое звучит реплика.
- `text` — текст реплики, тот же, что отправлен на озвучку.
- `file` — имя файла в этом каталоге. Формат MP3, его по умолчанию отдаёт ElevenLabs.

Реплику без файла игра пропускает и пишет предупреждение в лог.

## Предпросмотр

```sh
python3 -m http.server 8000 --directory assets/voice
```

Затем открыть http://localhost:8000/preview.html. Кнопка «Обновить» перечитывает `lines.json`.

## Воспроизведение в игре

```rust
fn on_run_start(mut voice: MessageWriter<PlayVoice>) {
    voice.write(PlayVoice::new("run_start"));
}
```
