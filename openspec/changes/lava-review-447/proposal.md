# Proposal

## Why

Code review изменений после сборки 0.1.0 (447) — Antigravity (gemini-4-neon-xhigh), решения по спорным
пунктам — со вторым рецензентом (Claude Opus 5.5). Новая лава (lava-flow) на склоне жгла не всю видимую
лаву, бюджет перелива соседние прорывы делили неверно, корка над свежей воронкой висела в воздухе, у
кромки озера корка пересобиралась без конца, а две далёкие ямы делали «лавой» для травы и луж всё между
ними. Спецификация обещала подъём озера от взрыва и «поддержание» озера и после исчерпания потока, а
физически источник тогда уже молчит.

## What Changes

- Лава жжёт там, где видна её горячая поверхность: высота между вершинами берётся как у сетки лавы.
- Бюджет перелива считается по истоку: налитое источником минус горячее в его яме.
- Когда поток исчерпан, источник больше не льёт; озеро стоит на уровне, который держит край ямы,
  взрыв уже не поднимает его.
- Изменение рельефа пересобирает сетки лавы и корки в этом месте: корка ложится в воронку.
- Остальное без изменения требований: заливка источника входит в шаг течения, крошки за краем ямы
  уходят в корку, грубая сетка квадратов 16 м вместо общей рамки, взрыв поднимает только ближнее
  озеро, корка без тени.
