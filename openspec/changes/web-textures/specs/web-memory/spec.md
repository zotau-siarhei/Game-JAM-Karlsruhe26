## ADDED Requirements

### Requirement: Браузерная версия помещается в память телефона
Браузерная сборка SHALL уменьшать текстуры моделей до 1024 пикселей по большей стороне.
Текстуры моделей MUST NOT держаться в памяти игры после передачи в видеокарту. Исходные
файлы в `assets/` MUST NOT меняться сборкой.

#### Scenario: Запуск на Android
- **WHEN** игрок открывает браузерную версию на телефоне Android с WebGPU
- **THEN** загрузка доходит до меню без потери устройства GPU

#### Scenario: Текстуры в браузерной сборке
- **WHEN** собирается браузерная версия
- **THEN** ни одна текстура внутри моделей в `target/web/assets` не больше 1024 пикселей по стороне

#### Scenario: Нативная версия
- **WHEN** запускается нативная версия
- **THEN** модели грузятся из исходных файлов с полными текстурами
