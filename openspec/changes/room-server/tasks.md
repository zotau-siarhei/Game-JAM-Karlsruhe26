## 4. Смена хоста

- [ ] 4.1 `Alive` раз в 0,5 с от хоста; служба объявляет хоста потерянным через 2 с без `Alive` или сразу по `YieldHost`; выбор нового по классу устройства и номеру, рост эпохи, `HostChanged` всем. Проверка: тест службы — потеря хоста из трёх игроков назначает лучшего по классу, эпоха растёт ровно на один
- [ ] 4.2 `YieldHost` при `AppLifecycle::Suspended` и `run::SystemPause` у хоста — с последней контрольной точкой. Проверка: Android-хост, свернуть игру — у клиента смена хоста без ожидания 2 с
- [ ] 4.3 `src/net/migrate.rs`: новый хост включает `authority()`, применяет контрольную точку, ставит реплицируемых по последнему снимку, выдаёт `NetId` новой эпохи; ИИ врагов выбирает цели заново. Проверка: три копии и локальный сервер — закрыть хоста, забег идёт у двоих, время, угроза, тревога и разрушения прежние
- [ ] 4.4 Остальные переключаются на нового хоста с `Rejoin`; клиент с более длинным журналом досылает хвост. Проверка: тест — хвост событий, которых нет у нового хоста, доходит до него и до всех
- [ ] 4.5 Надпись «Смена хоста…», мир стоит до первого снимка нового хоста; пакеты старой эпохи отбрасываются; вернувшийся прежний хост переподключается клиентом. Проверка: прежний хост вернулся через 20 с — он клиент, хост прежний новый
- [ ] 4.6 Один оставшийся игрок становится хостом и продолжает один. Проверка: две копии — закрыть хоста, клиент играет дальше один
