## Why

Третье из трёх изменений мультиплеера (`multi-rover` → `net-coop` → `room-server`). После
`net-coop` устройства играют по сети, но подключиться можно только флагом с IP-адресом, а через
мобильный интернет и домашние роутеры напрямую телефон до телефона часто не достучаться. И если
хосту позвонили или он свернул игру, забег кончается у всех. Нужен сервер, через который игроки
находят друг друга по коду или случайно, который соединяет их при любом роутере и назначает нового
хоста, когда прежний ушёл.

## What Changes

- Свой сервер на VPS, один процесс:
  - **служба комнат** — коды, быстрая игра, выбор хоста;
  - **ретранслятор** `iroh-relay` — пускает только игроков комнат.

  Мир сервер не считает, содержимого пакетов не видит.
- Соединение «сначала через ретранслятор, прямой путь в фоне»: забег начинается сразу, а когда
  пробивка NAT удаётся (в большинстве пар), пакеты идут напрямую без обрыва.
- **Смена хоста**: служба комнат — арбитр эпох. Ушедшего хоста (2 с без связи или сразу при уходе в
  фон) заменяет лучший по мощности игрок, забег продолжается с контрольной точки и журнала.
- **Возврат через сервер**: игрок, потерявший сеть, находит текущего хоста, даже если тот сменился.
- В меню — пункт «Вместе»: «Создать игру», «Войти по коду», «Быстрая игра».
- **Код комнаты**: 4 символа без похожих букв и цифр. Хост видит его в лобби, кнопкой «Поделиться»
  отправляет на Android и iOS через системное «Поделиться», на компьютере копирует в буфер обмена.
  Ссылок-приглашений нет.
- **Быстрая игра**: сервер ставит игрока в открытую комнату той же сложности или создаёт новую;
  забег стартует сам, когда собрались четверо или через 30 секунд после второго игрока.
- Игра знает ключ службы и корень сертификата ретранслятора заранее: ни домена, ни Let's Encrypt не
  нужно.
- Сервер не хранит IP-адреса и ничего не пишет на диск, кроме счётчиков нагрузки в журнал. Ключ узла
  у игрока новый на каждый запуск.
- Скрипт выкладки сервера на VPS и служба systemd.

## Capabilities

### New Capabilities

- `rooms`: комнаты с кодом, вход по коду, быстрая игра, «Поделиться», связь через ретранслятор с
  прямым путём, смена хоста, возврат через сервер, приватность и пределы сервера.

### Modified Capabilities

(нет: код комнаты, автостарт быстрой игры и смену хоста задаёт `rooms`. Требования `net-play` из
`net-coop` не меняются: уход хоста при прямом подключении по-прежнему кончает забег, прямое
подключение для разработки остаётся.)

## Impact

- Новый пакет `server/` (свой `Cargo.toml`, в сборку игры и APK не входит): `iroh` 1.x,
  `iroh-relay` 1.x с возможностью `server`, `tokio`, `rcgen` (корень и сертификат ретранслятора),
  `postcard`. Общий протокол — `src/net/protocol.rs`, сервер подключает его через `#[path]`, чтобы не
  заводить workspace.
- `src/net/server.rs`: адрес, ключ службы, корень ретранслятора; `src/net/link.rs` — режим комнаты
  (карта ретрансляторов — только свой).
- `src/net/migrate.rs`: `Alive`, `YieldHost`, `HostChanged`, подхват мира новым хостом.
- `src/menu.rs`: подэкран «Вместе», ввод кода экранной клавиатурой из рекордов; надпись «Смена хоста…».
- «Поделиться»:
  - Android — JNI (`jni`, `ndk-context` уже приходят с `android-activity`, проверить версии);
  - iOS — `UIActivityViewController` (`objc2-ui-kit`);
  - компьютер — буфер обмена (`arboard`).
- `scripts/deploy-server.sh`, `server/space-guard-server.service`.
- Нужен VPS (например Hetzner, около 5 € в месяц) с открытыми TCP 443, UDP 7447 и UDP 7842: покупает и
  даёт доступ пользователь.
