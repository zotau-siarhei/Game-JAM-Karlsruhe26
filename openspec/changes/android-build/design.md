## Context

Игра — бинарный крейт. Android загружает нативный код как библиотеку `.so`, файлы игры лежат внутри
APK и обычным чтением с диска недоступны. Gradle на машинах разработки не установлен.

## Goals / Non-Goals

**Goals:**
- Собирать устанавливаемый APK одной командой, не замедляя обычную сборку.
- Запускаться на телефонах с Adreno, где уже падала браузерная версия.

**Non-Goals:**
- Сенсорное управление и вибрация геймпада на Android.
- Публикация в магазине и подпись релизным ключом.

## Decisions

- **Отдельный пакет `android/` с `path = "../src/main.rs"`.** Перенос кода в `lib.rs` задел бы все
  параллельные ветки, а `[lib]` в корневом пакете собирал бы игру дважды. Цена — список зависимостей
  повторяется; версии берутся из корневого `Cargo.lock`.
- **`NativeActivity` вместо `GameActivity`.** Не нужен Java-код, поэтому APK собирают `aapt2`,
  `zipalign` и `apksigner` без Gradle.
- **Правка шейдера в `Assets<Shader>` в расписании `Last`.** Шейдер меняется в кадре загрузки, до
  передачи в рендер, поэтому конвейер с опасной выборкой не собирается.
- **Синхронная сборка конвейеров.** На Adreno 810 при пустом кэше шейдеров фоновая сборка приводила
  к зависанию GPU и потере устройства в 4 запусках из 5. С синхронной сборкой холодный запуск прошёл.
- **Геймпад через патч android-activity.** Очередь ввода читает только winit и делает из джойстика
  касания, теряя правый стик и курки. Скрипт сборки копирует крейт и добавляет фильтр ввода; весь winit
  и Java-код для этого не нужны.
- **Минимальный API 29.** На 64-битных устройствах с Android 10 Vulkan 1.1 обязателен.
- **Только адаптивная иконка.** При API 29 запасные PNG не нужны. Фон — цвет, передний и монохромный
  слои — PNG из `android/icon/source.png`; рисунок вписан в безопасный круг 66 dp.

## Risks / Trade-offs

- Без геймпада и клавиатуры игрой нельзя управлять → сенсорное управление — отдельное изменение.
- Долгий кадр при ожидающем событии ввода вызывает системное «приложение не отвечает» → на эмуляторе
  это видно при старте забега, на телефоне не проверено.
- Холодный запуск с синхронной сборкой на телефоне проверен один раз → повторить на итоговой сборке.
- Производительность на телефоне не измерена → по умолчанию низкое качество.
