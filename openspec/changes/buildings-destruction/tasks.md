## 2. Объекты поверхности

- [x] 2.2 Меши и общие материалы всех видов с вариантами, создание и удаление вместе с участком, без теней у мелких; проверка: `cargo run`, в кадре десятки объектов, видны рощи и россыпи, на полной скорости FPS стабилен на M2
- [x] 2.3 Столкновения: крупные объекты выталкивают машины со скольжением и останавливают пули, мелкие сминаются машиной с разлётом осколков; проверка: `cargo run`, луноход скользит вдоль валуна, сносит забор и кусты не замедляясь, валун закрывает от пуль

## 3. Дом в бою

- [x] 3.1 Прямоугольный коллайдер дома: выталкивание лунохода и врагов со скольжением вдоль стены, остановка пуль о стены; проверка: `cargo test` с тестом «круг, пересекающий прямоугольник, выталкивается наружу», `cargo run`, луноход скользит вдоль стены, дом закрывает от пуль врага
- [x] 3.2 Прочность дома, урон от взрыва по ближайшей точке прямоугольника, вздрагивание при попадании, дым после половины прочности, событие разрушения ровно один раз, запись статуса в хранилище; пока разрушение — мгновенная замена руиной; проверка: `cargo run`, мортира сносит дом с одного попадания, пулемёт за несколько секунд, после отъезда и возвращения дом не восстанавливается

## 4. Обломки и обрушение
