## Context

Страница `web/index.html` растягивает холст на всё окно, экран загрузки закрывается касанием или
клавишей (`enter()`), это же касание будит звук. Браузеры дают полный экран только из обработчика
жеста пользователя. Поддержка: Fullscreen API — Chrome, Edge, Firefox, Safari на macOS и iPad
(`webkitRequestFullscreen`); Safari на iPhone — нет. Поворот экрана (`screen.orientation.lock`)
работает только в полноэкранном режиме на Android. Keyboard Lock API (`navigator.keyboard.lock`) —
Chrome и Edge, только в полноэкранном режиме.

## Goals / Non-Goals

**Goals:**
- На Android и iPad игра занимает весь экран с первого касания.
- На компьютере полный экран — по желанию, кнопкой.
- На iPhone — честная подсказка, как получить игру без интерфейса браузера.

**Non-Goals:**
- Сенсорное управление, офлайн-режим.

## Decisions

### Полный экран — у всей страницы
`requestFullscreen` у `document.documentElement`, а не у холста: в полный экран уходят и экран
загрузки, и кнопка. Холст подстраивается сам: Bevy следит за размером через `ResizeObserver`.

### Автоматически — только на сенсорных устройствах
На телефоне и планшете (та же проверка, что выбирает низкое качество) касание «начать» вызывает
полный экран и поворот в альбомную ориентацию; ошибки (отказ браузера) молча игнорируются. На
компьютере автоматический полный экран навязчив — там только кнопка.

### Esc у игры
В полном экране Chrome по Esc выходит из него, и игра теряет паузу. `navigator.keyboard.lock(["Escape"])`
отдаёт Esc игре, а браузер сам показывает подсказку «удерживайте Esc для выхода». Снимается при
выходе из полного экрана.

### Кнопка
Квадрат 44×44 px (минимальная цель касания) в правом верхнем углу с отступом по безопасной зоне,
полупрозрачная, ярче при наведении. Нажатие не уходит в игру: кнопка лежит поверх холста, а
`pointerdown` у неё не всплывает. После нажатия фокус возвращается холсту. Нет API и это не iPhone
(старый браузер) — кнопки нет. Игра уже открыта как приложение (`display-mode: fullscreen`,
`standalone` или `navigator.standalone`) — кнопки нет.

### iPhone
Кнопка показывает панель-подсказку на 6 с: «Tap Share, then Add to Home Screen to play full screen».
После установки игра открывается по манифесту (`apple-mobile-web-app-capable`,
`black-translucent`) без интерфейса Safari.

### Манифест
`display: fullscreen`, `orientation: landscape`, `start_url: "./"`, `scope: "./"`, цвет фона и темы
чёрные, иконки 192 и 512 px PNG (из `web/icon.svg` через `rsvg-convert`, сгенерированы один раз и
лежат в репозитории) и SVG. Service worker не нужен: Chrome устанавливает приложение и без него.

## Risks / Trade-offs

- Браузер может отказать в полном экране (настройки, встроенный браузер мессенджера) → ошибка
  игнорируется, игра работает в окне, кнопка остаётся.
- Блокировка Esc неизвестна игроку → Chrome сам показывает подсказку при входе в полный экран.
