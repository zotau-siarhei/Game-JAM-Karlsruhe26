## Context

Танк собран из частей (`tank_look`): корпус, башня, две гусеницы; башня поворачивается по
`TankGun.yaw`. Поведение — `enemy::drive_tanks`: заход с фланга, остановка, секунда прицеливания с
красной линией, импульс лазера по курсу корпуса. Ракетчик — `drive_rocketeers`: укрытия, выглядывание,
ракета `FireRocket` при прямой видимости. Ящики (`pickups.rs`) и аптечка (`repair.rs`) — кубы из
примитивов, перехватчик — запасной облик из примитивов (`spawn_interceptor_spare`).

## Goals / Non-Goals

**Goals:**
- Два танка на одном шасси: ракетный (нынешняя башня) и лазерный (новая установка).
- Убрать ракетчика целиком.
- Модели для ящиков, аптечки, перехватчика, лазерной установки.

**Non-Goals:**
- Новые числа урона ракет: ракета танка — та же `FireRocket`, что у игрока и босса.
- Перебалансировка волн сверх замены ракетчика.

## Decisions

1. **Один компонент `HeavyTank` с видом оружия `TankArm { Rockets, Laser }`.** Заход с фланга общий.
   Ракетный танк не ждёт, пока довернёт корпус: стреляет, когда башня смотрит на луноход
   (ракета летит в цель, а не по курсу), без красной линии прицела — её видно только у лазера.
   Лазерный — ровно прежний танк. Альтернатива — два отдельных компонента и две системы — дала бы
   копию захода с фланга.
2. **Состав волн.** Ракетный танк занимает место ракетчика по порогу угрозы, стоимость 4, здоровье
   меньше лазерного (160 против 220). Лазерный танк — прежний порог и стоимость 5. Золотой ящик падает
   из обоих танков.
3. **Модели через `Models::spawn_visual` с запасным обликом из нынешних примитивов.** Пока файла нет
   или модель не одобрена (её нет в `models.json`), игра выглядит как раньше. Свечение ящика под цвет
   оружия остаётся дочерними примитивами поверх модели.
4. **Модели Meshy** — картинка `nano-banana-2`, затем Image to 3D `meshy-t2.5` Smart Topology с
   текстурой `meshy-n1`, бюджет треугольников: перехватчик 5000, лазерная установка 2500, ящики и
   аптечка по 1500. Лазерная установка — отдельная башня с началом координат в середине низа, как
   `enemy_tank_turret`: дульный срез мерится по модели.

## Risks / Trade-offs

- [Модели без одобрения] → в `assets/models` и `models.json` попадают только после одобрения в
  каталоге; код уже ждёт их id, без файла — примитивы.
- [Ракетный танк сильнее ракетчика по здоровью] → стоимость в волне выше (4 против 3) и меньше
  здоровья, чем у лазерного.
