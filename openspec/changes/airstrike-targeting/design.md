## Context

`airstrike::call_airstrike` по `just_pressed(Left)` тратит заряд и ставит `spawn_strike` в
`AimPoint` с направлением от лунохода. Камера (`camera.rs`) смотрит под 45° с расстояния 35 м,
круто только у стен кратеров; `fit_view` подбирает угол обзора по экрану. Замедление времени —
`impact.rs`, `run_slowmo` сам ставит `Time<Virtual>::relative_speed` по реальному времени.
Участки рельефа подгружаются на 3 участка по 32 м вокруг `Focus` (±112 м) — вид сверху на 80 м
в них помещается. Прицел мышью — `aim.rs` (луч из камеры на рельеф), стиком — `stick_aim.rs`
(курсор по L2).

## Goals / Non-Goals

**Goals:** режим наведения как отдельное состояние авиаудара, без нового `GameState`;
плавные переходы времени и камеры; одинаковое управление мышью и геймпадом.

**Non-Goals:** мини-карта как экран наведения; наведение для других видов оружия; подгрузка
мира дальше нынешнего радиуса.

## Decisions

- **Состояние** — ресурс `AirstrikeTargeting { open, real_elapsed, point, yaw_offset, blend }` в
  `airstrike.rs`. `blend` 0→1 за 0,3 с реального времени при входе и обратно при выходе: от него
  берут скорость времени и вид камеры. Отдельный `GameState` не нужен: игра идёт, только медленно;
  наборы `GameSet` работают как в забеге.
- **Время** — `airstrike` ставит `relative_speed = lerp(1, 0.2, blend)`; `impact::run_slowmo`
  пропускает кадр, если `blend > 0`, и не сбрасывает скорость в 1, пока режим открыт.
  Предел 6 с считается по `Time<Real>`.
- **Камера** — `camera.rs` читает публичный `blend` и смешивает обычный вид с видом наведения:
  наклон 82°, расстояние ×2,6, угол обзора без изменений. `Focus` остаётся на луноходе, поэтому
  подгрузка мира не меняется.
- **Прицел** — точка наведения берётся из `AimPoint`: `aim.rs` уже бросает луч через новую камеру;
  с геймпада в режиме правый стик сразу ведёт курсор (как при зажатом L2), без захвата врагов.
  Точка ограничивается кругом 80 м вокруг лунохода.
- **Превью отметки** — те же меши отметки, что у `spawn_strike`, но полупрозрачные и без дыма,
  пересоздаются при смене точки или поворота (дёшево: 8 сегментов). Красный цвет — та же
  проверка пересечения с луноходом.
- **Ввод** — в режиме `weapons` не читает колесо, `run::pause_on_escape_or_blur` не ставит паузу
  по Esc (потеря фокуса — ставит и закрывает режим). Геймпад: бамперы в режиме — поворот, East —
  отмена; в `gamepad::virtual_for` это виртуальные клавиши, которые читает `airstrike`.
- **Подтверждение** — существующий путь `spawn_strike` с точкой и направлением из режима; клик
  подтверждения гасится, чтобы не стал выстрелом другого оружия после выхода.

## Risks / Trade-offs

- [Вид почти сверху показывает край загруженного мира на узком экране] → расстояние камеры
  ограничено так, чтобы видимый круг не выходил за ±100 м; на телефоне вертикально — меньше отъезд.
- [Замедление 20 % в режиме даёт игроку «паузу» для планирования] → предел 6 с и автоудар.
- [Смешивание двух систем времени] → режим — единственный владелец скорости времени, пока открыт.
