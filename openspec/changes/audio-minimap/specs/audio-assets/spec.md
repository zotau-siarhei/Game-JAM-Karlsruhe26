## Purpose

Звуковые ресурсы игры: как они создаются через ElevenLabs и хранятся в проекте.

## ADDED Requirements

### Requirement: Генерация по списку
Звуки, музыка и реплики штаба SHALL генерироваться через ElevenLabs отдельной утилитой проекта
по списку в файле: для каждого ресурса — имя файла, тип и описание или текст. Утилита MUST
пропускать уже сгенерированные файлы и генерировать заново только изменённые или по явной просьбе.

#### Scenario: Добавлена реплика
- **WHEN** разработчик добавил в список новую реплику и запустил утилиту
- **THEN** утилита генерирует только её, остальные файлы не трогает

### Requirement: Ключ доступа
Ключ ElevenLabs SHALL браться из переменной окружения. Ключ MUST NOT попадать в репозиторий,
в файлы ресурсов и в сборку игры.

#### Scenario: Нет ключа
- **WHEN** утилита запущена без ключа
- **THEN** она завершается с понятным сообщением, какую переменную задать

### Requirement: Игра без сети
Игра SHALL проигрывать только готовые файлы из ресурсов проекта и MUST NOT обращаться к сети.
Отсутствующий файл MUST NOT ломать игру: соответствующий звук просто не звучит.

#### Scenario: Запуск без интернета
- **WHEN** игра запущена на компьютере без сети
- **THEN** все звуки, музыка и реплики работают

#### Scenario: Файла нет
- **WHEN** одного звукового файла нет в ресурсах
- **THEN** игра запускается и работает, этот звук не звучит, в журнал пишется предупреждение

### Requirement: Ресурсы в репозитории
Сгенерированные файлы и список ресурсов SHALL храниться в репозитории, чтобы любой участник
команды собирал игру со звуком без доступа к ElevenLabs.

#### Scenario: Новый участник
- **WHEN** новый участник клонирует репозиторий и запускает игру
- **THEN** звук работает без генерации
