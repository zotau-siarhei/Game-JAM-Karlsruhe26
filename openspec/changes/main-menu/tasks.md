## 1. Настройки и сложность

- [ ] 1.1 `src/settings.rs`: ресурс `Settings` (качество, громкости общая/музыка/эффекты/голос, вибрация, сложность) с чтением и записью `settings.json` через временный файл, в браузере только в памяти; `quality.rs` берёт и пишет качество через `Settings`, Q на паузе работает как раньше; проверка: тесты «прежний файл с одним качеством читается, остальное по умолчанию» и «запись и чтение дают те же настройки», `cargo build`
- [ ] 1.2 `src/difficulty.rs`: `Difficulty { Easy, Normal, Hard }` с числами из спецификации `difficulty`, ресурс `RunDifficulty` ставится из `Settings` при начале забега; урон по луноходу в `combat::apply_damage`, рост угрозы в `waves.rs`, `RegenSettings` в `regen.rs`; проверка: тесты «урон 10 на тяжёлой — 15», «угроза 2 минут на лёгкой — 1,5», `cargo build`
- [ ] 1.3 Помощь прицела с геймпада по сложности: `stick_aim` берёт ширину захвата, удержания и замедление курсора из `RunDifficulty` (лёгкая 4 / 6 м / 0,25, нормальная 2,5 / 4 м / 0,4, тяжёлая 1,8 / 3 м / 0,6); проверка: тест «враг в 3,5 м сбоку ловится на лёгкой и не ловится на нормальной», `cargo build`
- [ ] 1.4 Громкость и вибрация из `Settings`: множитель общая × группа в `music.rs` (с приглушением на паузе), `sound.rs` (эффекты, интерфейс, мотор) и `voice.rs`; играющие музыка и мотор подхватывают изменение сразу; выключенная вибрация гасит толчки и цвет панели в `haptics.rs`; проверка: `cargo build`, при голосе 0 % реплики не слышны, субтитры есть
- [ ] 1.5 Рекорды по сложностям: три таблицы (`records-easy.json`, `records.json`, `records-hard.json`), результат забега и экран конца забега — таблица его сложности, лучшее время в меню — выбранной; проверка: тест «результат на лёгкой не попадает в таблицу нормальной», `cargo build`

## 2. Меню
