## 1. Угроза и волны

- [x] 1.1 Ресурс угрозы от времени и весов разрушений, модуль баланса с кривыми; проверка: `cargo test` с тестами «угроза не убывает» и «снос дома повышает угрозу больше, чем секунда времени», `cargo build` — сделано: `Threat` и модуль `balance` в `src/waves.rs`; угрозу сейчас поднимают время и взрывы оружия игрока (вес кратера), вес дома задан, но не подключён: сообщения о сносе дома ещё нет
- [x] 1.2 Директор волн: передышка, бюджет, покупка типов по угрозе, направления с разбросом, предел живых, объявление волны на экране; убрать простое появление по таймеру; проверка: `cargo test` с тестом «первая волна только из таран-стрелков», `cargo run`, волны приходят с нескольких сторон, номер волны объявляется — сделано в `src/waves.rs`: передышка, бюджет, 1–3 направления с разбросом ±25°, предел 24 живых, надпись «WAVE N»; появление по таймеру убрано, врага ставит сообщение `SpawnEnemy` из `src/enemy.rs`; тип врага пока один, поэтому покупка по угрозе выбирает из одного; проверено прогоном со скрытым окном на трёх волнах, картинку глазами не смотрел

## 2. Источники появления

- [ ] 2.1 Десантные капсулы: отметка на земле, падение с огненным следом, взрыв с кратером и уроном, раскрытие и выезд врага; проверка: `cargo run`, отметка видна заранее, капсула оставляет кратер и ранит луноход рядом
- [ ] 2.2 Выход врагов из домов: выбор целого дома в секторе волны, выбитая дверь со щепками, выезд сквозь стену своего дома, сохранение выбитой двери; проверка: `cargo run`, враги выезжают из домов ближнего посёлка, дом остаётся целым с отверстием

## 3. Новые типы врагов

- [ ] 3.1 Общие примитивы поведения: рулёжка к точке с объездом по трём лучам и выходом из застревания, проверка видимости с домами и валунами; мортирщик с дистанцией, отступлением, стрельбой с упреждением и красной отметкой падения; проверка: `cargo run`, мортирщик держит дистанцию и достаёт луноход в кратере, враги объезжают дома
- [ ] 3.2 Робот-ракетчик: поиск укрытия по кандидатам с бонусом за кратер, укрытие, выглядывание с выстрелом ракетой, смена укрытия при его потере; проверка: `cargo run`, ракетчик прячется в кратере или за домом, высовывается для выстрела, после сноса дома ищет новое укрытие
- [ ] 3.3 Тяжёлый танк: заход с фланга, подготовка с видимой линией прицела, импульс лазера через общее сообщение выстрела с прорезом рельефа; проверка: `cargo run`, танк заходит сбоку, линия прицела видна секунду, импульс прорезает холм

## 4. Босс

- [ ] 4.1 Колосс: предупреждение, высадка с кратером, полоса здоровья, цикл атак с подготовкой — залп мортиры по отметкам, веер ракет, таран со сносом домов, — гибель с серией взрывов, замедлением, кратером и ящиками; каждая четвёртая волна; проверка: `cargo run` с временно заниженным номером волны босса, все три атаки и гибель работают, полоса здоровья убывает

## 5. Тревога и Служба

- [ ] 5.1 Ресурс тревоги с очками, ступенями, пределом и спадом после затишья; индикатор ступеней со вспышкой; проверка: `cargo test` с тестами «снос дома поднимает тревогу», «тревога не превышает пятую ступень», «после затишья тревога спадает», `cargo run`, индикатор реагирует на снос домов
- [ ] 5.2 Служба защиты жителей: фракция без взаимного урона с врагами, три вида машин по ступеням в бело-оранжевом облике без полицейских признаков, появление со стороны посёлка, окружение кольцом, стрельба при видимости, отъезд при нулевой тревоге; проверка: `cargo run`, после сноса посёлка приезжают машины Службы, окружают луноход, не стреляют во врагов, при затишье уезжают

## 6. Баланс

- [ ] 6.1 Настроить кривые угрозы, бюджеты, здоровье и урон по пяти реальным забегам: новичок погибает за 2–3 минуты, опытный игрок доживает до 5 минут и видит хотя бы одного босса; проверка: `cargo build --release`, записанные длительности пяти забегов на MacBook Air M2 в пределах цели, частота кадров на поздних волнах без заметных провалов
