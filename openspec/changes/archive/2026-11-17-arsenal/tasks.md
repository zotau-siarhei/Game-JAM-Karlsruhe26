## 1. Инвентарь

- [x] 1.1 Перечисление видов оружия с таблицей параметров, ресурс инвентаря с боезапасом, сообщение выстрела; перевести пулемёт и мортиру на него, мортире — стартовый запас и расход; выбор клавишами 1–6 и колесом по имеющимся, переключение на пулемёт при опустевшем оружии; проверка: `cargo test` с тестами «подбор не превышает предел», «пустое оружие не выбирается колесом», `cargo run`, мортира кончается после восьми выстрелов и игра переходит на пулемёт — сделано без общего сообщения выстрела `Fire`: оружие тратит заряд через `Inventory::spend`
- [x] 1.2 Панель оружия внизу экрана: ячейки имеющихся видов с клавишей, значком и патронами, выделение текущего, приглушение пустого, анимация новой ячейки, мигание при попытке выбрать пустое; проверка: `cargo run`, панель отражает расход и смену оружия
- [x] 1.3 Тест пулемёта учитывает масштаб лунохода `ROVER_SCALE`: дуло вынесено и поднято в мерах модели, умноженных на масштаб; проверка: `cargo test`, тест `bullet_flies_from_the_muzzle_towards_the_aim_point`

## 2. Ракеты

- [x] 2.1 Ракета: полёт низко над рельефом, след дыма и огня, подрыв о рельеф, объект, дом, врага или в точке прицела, малый кратер; проверка: `cargo run` с временно выданными ракетами, ракета взрывается о холм с малым кратером, след дотлевает после подрыва
- [x] 2.2 Самонаводящиеся ракеты: выбор целей у прицела, метки захвата, залп веером, наведение с ограниченным поворотом, перенацеливание при гибели цели; проверка: `cargo run`, залп по трём врагам разбирает всех, при одном враге все ракеты летят в него, без врагов падают у прицела

## 3. Лазер

- [x] 3.1 Импульс лазера: луч с гаснущей яркостью, вспышка, искры, урон всем коллайдерам на отрезке кроме лунохода, срезанные деревья и дома; проверка: `cargo run`, один импульс поражает несколько врагов в ряд и срезает деревья
- [x] 3.2 Траншея: операция прореза рельефа вдоль отрезка ниже высоты луча с сообщением об изменении рельефа, раскалённые края с остыванием, дым и искры вдоль прореза, сохранение; проверка: `cargo test` с тестом «прорез не поднимает высоты и не трогает ровное место ниже луча», `cargo run`, луч прорезает холм насквозь, края светятся и темнеют, по траншее можно проехать — выжженная полоса на ровном месте, искры и дым вдоль прореза доделаны по находке ревью Н11

## 4. Авиаудар

- [x] 4.1 Вызов: отметка по рельефу по направлению от лунохода, красная при пересечении с луноходом, пульсация и сигнальный дым, таймер; пролёт самолёта с тенью; серия бомб с баллистикой, мощными взрывами, большими кратерами и продлением замедления; проверка: `cargo run` с временно выданным авиаударом, удар по посёлку оставляет борозду кратеров и руины, замедление срабатывает один раз на серию

## 5. Подбираемые предметы

- [x] 5.1 Общий подбираемый предмет с подбором проездом, всплывающей надписью, посадкой на рельеф; ящики на парашютах с периодичностью, пределом, весом мест разрушений и содержимым по времени забега; проверка: `cargo test` с тестом «до минуты в ящиках только мортира и ракеты», `cargo run`, ящики падают чаще у кратеров и руин, подбор даёт патроны или новое оружие
- [x] 5.2 Оружие врагов: компонент носимого оружия, доля таран-стрелков с ракетами, стрельба через сообщение выстрела, выпадение светящегося предмета при гибели, мигание и исчезновение; проверка: `cargo run`, убитый ракетчик оставляет ракеты, неподобранный предмет мигает и исчезает

## 6. Исправления по архитектурному ревью

- [x] 6.1 Б3: самолёт авиаудара заходит дальше упреждения сброса первой бомбы (заход около 122 м вместо 90), бомбы ложатся бороздой; отметка держится до падения последней бомбы
- [x] 6.2 Б4: предел ящиков и аптечек считает только предметы ближе 70 м к луноходу, предметы дальше 150 м убираются
- [x] 6.3 Б5, Б32: ремонт и аптечка — доли здоровья лунохода (10 % в секунду и 35 %, как при здоровье 100, когда числа настраивались); здоровье прибавляет сообщение `combat::Heal`
- [x] 6.4 Б31: вспышка попадания перекрашивает меши сущности и всех её потомков: видно попадание по луноходу
- [x] 6.5 Б24: мортира игрока стреляет сообщением `FireShell`, жители пугаются точки падения
- [x] 6.6 Б25: сигнальный дым авиаудара пульсирует от своей высоты; перезарядки мортиры, ракет и лазера сбрасываются по `WorldRebuilt`; ящик при полном боезапасе не подбирается; реплика `ammo_empty` — по сообщению `AmmoRanOut`, когда потрачен последний заряд
- [x] 6.7 Н11: лазер выжигает полосу на ровном месте под низким лучом, вдоль прореза летят искры и поднимается дым
- [x] 6.8 Производительность: след ракеты — вытянутые клубы раз в 0,07 с, не больше 90 клубов сразу (было около 50 на ракету)
- [x] 6.9 Проверить в игре: борозда авиаудара, вспышка попадания по луноходу, ремонт и аптечка после нового баланса, выжженная полоса лазера, след ракет — 2026-11-17: Sergei Zotov проверил в игре
