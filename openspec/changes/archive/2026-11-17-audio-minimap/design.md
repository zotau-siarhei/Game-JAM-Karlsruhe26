## Context

Все предыдущие изменения публикуют события, на которые можно повесить звук: `Fire`, `Explosion`,
`BuildingDestroyed`, `Died`, `ResidentDied`, сход поезда, рост тревоги, начало волны, появление
босса, подбор, состояния `Menu`, `Playing`, `Paused`, `GameOver`, замедление через `Time<Virtual>`.

Изменение `voice-lines` Сергея Зотова уже реализовано и задаёт основу звука:
- список реплик `assets/voice/lines.json` с полями `id`, `event`, `text`, `file`, файлы MP3 рядом;
- плагин `VoicePlugin` в `src/voice.rs`: читает список через `serde_json` при запуске, загружает
  существующие файлы, пишет в лог отсутствующие;
- сообщение `PlayVoice(id)`: одновременно звучит одна реплика, новая обрывает текущую, частоту
  ограничивает тот, кто отправляет;
- страница предпросмотра `assets/voice/preview.html`;
- у Bevy включена фича `mp3`, в проекте есть `serde` и `serde_json`.

Это изменение строится поверх этих решений и не меняет их.

## Goals / Non-Goals

**Goals:**
- Звуки и музыка устроены так же, как реплики: список JSON, файлы рядом, проигрывание по
  идентификатору сообщением.
- Логика выбора реплик штаба поверх `PlayVoice`, без изменения поведения проигрывания.
- Игра без сети, мини-карта, которая обновляется дёшево.

**Non-Goals:**
- Очередь реплик: `voice-lines` выбрал обрыв текущей реплики, здесь только отбор поводов.
- Генерация звука во время игры, физически точный пространственный звук.

## Decisions

### Звуки и музыка по образцу реплик
`assets/sfx/sounds.json` и `assets/music/tracks.json` в формате `lines.json`: `{"lines": [{"id", "event",
"text", "file"}]}`. Поле `text` для звука и музыки — описание для генерации в ElevenLabs. Тип записи
и разбор берутся из модуля `voice`: структура записи и функция разбора выносятся в общий модуль
`sound_list`, а `voice` использует его без изменения поведения. Альтернатива — свой формат
списка для звуков: два способа делать одно и то же в одном проекте.

### Звуковые эффекты — сообщение `PlaySound`
Плагин `SoundPlugin` по образцу `VoicePlugin`: при запуске читает `sounds.json`, загружает
существующие файлы, пишет в лог отсутствующие. Сообщение `PlaySound { id, position: Option<Vec3> }`.
В отличие от голоса, звуки звучат одновременно, с пределом экземпляров на вид.
Вариации — записи с общим префиксом и номером: `explosion_1`, `explosion_2`; `PlaySound` с
идентификатором `explosion` выбирает случайную запись группы. Скорость воспроизведения 0,9–1,1.
Пределы одновременных экземпляров: пулемёт 6, взрыв 5, обрушение 3, жители 4.

### Подписка на события
Модуль звука читает игровые события и отправляет `PlaySound`. Таблица «событие → идентификатор» —
в одном модуле. Ни одна игровая система не вызывает звук напрямую.

### Пространственность — панорама и затухание
Встроенный пространственный звук Bevy со слушателем на луноходе, повёрнутым по осям экрана, а не
корпуса. Затухание вручную: `1 / (1 + (d/25)²)`, звуки дальше 90 м не создаются. Запасной вариант —
моно с ручной громкостью без панорамы.

### Звук и время
Звуки мира получают скорость воспроизведения, умноженную на скорость `Time<Virtual>`, поэтому
замедление растягивает звук. На паузе звуки мира ставятся на паузу через `AudioSink`.
Реплики штаба на паузе не ставятся: `voice-lines` их не различает, а реплика короткая.

### Музыка
`tracks.json`: `menu`, `lull`, `combat`, `boss`, `game_over`, `death_sting`. Плагин `MusicPlugin`
с ресурсом `MusicState` и двумя проигрывателями для перекрёстного затухания за 2 с. Конец забега —
`death_sting` обрывает музыку, затем `game_over`. На паузе громкость 0,5. Приглушение под голос —
0,35, пока звучит реплика. Чтобы знать это, модуль `voice` открывает наружу признак звучания —
публичный ресурс или публичная метка сущности реплики. Это единственная правка в модуле `voice`,
поведение проигрывания не меняется.

### Голос штаба — отбор поводов поверх `PlayVoice`
Модуль `hq` читает игровые события и решает, отправлять ли `PlayVoice`.
- **Поводы и приоритет.** Таблица «событие → базовый идентификатор → важный или обычный».
  Базовые идентификаторы — те, что уже есть в `lines.json`: `run_start`, `first_crater`,
  `house_destroyed`, `alarm_rising`, `boss_appears`, `train_derailed`, `death`; новые поводы
  добавляют строки в `lines.json`.
- **Отбор.** Обычный повод отбрасывается, если реплика звучит или закончилась меньше 4 с назад.
  Важный — `boss_appears`, `low_health`, `death`, `new_record` — отправляется сразу и обрывает
  текущую по правилу `voice-lines`. Отложенных поводов нет, как и решено в `voice-lines`:
  опоздавшая реплика хуже пропущенной.
- **Тон и варианты — соглашение об идентификаторах.** Вариант — запись с идентификатором
  `<база>.<тон>.<n>`, где тон — `calm`, `worried` или `panic`, например `house_destroyed.panic.2`.
  Модуль выбирает случайный вариант текущего тона, кроме сыгранного последним; если вариантов
  тона нет — более спокойного; если нет ни одного — саму базовую запись. Формат `lines.json` и
  предпросмотр не меняются, варианты добавляются строками без кода.
- **Тон** — 0, 1 или 2 по доле веса разрушений в угрозе из `waves-alarm`.
- **Субтитр** — узел внизу по центру над панелью оружия, тёмная подложка, «Штаб:» и `text`
  реплики. Показывается, пока звучит реплика, и сменяется при обрыве.

### Утилита генерации
Два скрипта на Python 3 без сторонних пакетов, запросы через `urllib`. `scripts/gen_audio.py` читает
`sfx/sounds.json` и `music/tracks.json`, `scripts/gen_voice.py` — `voice/lines.json`. Для каждой
записи с отсутствующим файлом скрипт генерирует файл через ElevenLabs: синтез речи для реплик,
генерация звуковых эффектов для звуков, генерация музыки для треков; эффекты на реплики накладывает
`ffmpeg`. Ключ — `ELEVENLABS_API_KEY` из окружения. Флаг `--only <id,…>` перегенерирует названные записи. Существующие файлы без флага
не трогаются, поэтому файлы, озвученные вручную, сохраняются.
Альтернативы: бинарник на Rust с `ehttp` — лишняя зависимость в сборке игры (`ureq`, `rustls`,
`ring`) ради утилиты; запросы из игры — нужна сеть и ключ на компьютере Open Arcade.

### Мини-карта
Круг диаметром 200 пикселей в правом верхнем углу, охват 160 м. Местность — текстура 128×128,
пересчитывается раз в 0,5 с из цветов вершин хранилища рельефа, поверх — пути и посёлки. Метки —
пул из 64 узлов интерфейса: враги — красные треугольники, Служба — оранжевые кружки, босс — большой
знак, поезд — серая полоска, ящик — жёлтый квадрат, аптечка — белый крест, отметки опасности —
мигающие красные кольца. Метки дальше охвата прижимаются к краю круга. Рамка кадра — проекция
углов экрана на плоскость под луноходом.
Альтернатива — вторая камера в текстуру: второй проход рендера, дорого на M2.

### Сброс при новом забеге
Музыка переходит к треку забега, звучащая реплика и субтитр убираются, память последних вариантов
реплик и отметка «первый кратер» и «первый дом» сбрасываются. Мини-карта очищает метки и текстуру.

## Risks / Trade-offs

- [Обрыв реплик раздражает] → отбор обычных поводов с паузой 4 с, обрывают только важные.
- [Соглашение об идентификаторах забывается] → описывается в `assets/voice/README.md`, тест
  проверяет, что у каждого варианта есть базовая запись.
- [ElevenLabs генерирует неудачный звук] → `--force <id>` и правка описания в списке.
- [Музыка не зацикливается без шва] → короткое затухание на стыке.
- [Ключ попадёт в репозиторий] → только переменная окружения, `.env` в `.gitignore`.
