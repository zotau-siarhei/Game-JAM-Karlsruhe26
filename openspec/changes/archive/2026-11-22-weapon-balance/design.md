## Context

Урон взрыва — `combat::explosion_damage`: расстояние от точки взрыва до `GlobalTransform` цели.
Взрывы лунохода по врагам — `core_blast_damage`: полный урон до 0,75 R, спад до нуля на 1,25 R.
Ракета (`rockets::fly_rockets`) подрывается, когда отрезок полёта проходит ближе радиуса коллайдера
цели + 0,3 м, в конце отрезка — то есть у края корпуса.

## Goals / Non-Goals

**Goals:** прямое попадание ракеты — полный урон; босс — около 30 ракет; лазер — танк с одного импульса.

**Non-Goals:** урон по луноходу, сложность, мортира, авиаудар, пулемёт; расчёт урона всех взрывов
до края цели.

## Decisions

1. **Взрыв в центре поражённой цели, а не расстояние до края для всех взрывов.** Расстояние до края
   для всех взрывов лунохода расширило бы площадь мортиры и бомб по крупным врагам на радиус их
   корпуса (у танка +3,3 м) — это другой баланс. Правка только в ракетах: при попадании точка взрыва —
   центр ближайшей поражённой цели. Соседи получают урон от неё, кратер и вспышка — там же.
2. **Мощность ракеты 0,85.** 85 × 2 = 170 ≥ 160 (ракетный танк), 85 × 3 = 255 ≥ 220 (лазерный).
   Кратер ракеты (R·p = 3,4) остаётся меньше кратера самонаводящейся (3,6) и мортиры.
3. **Броня босса — компонент `BlastArmor { light_power, share }` в `combat.rs`.** Взрыв с мощностью меньше
   `light_power` (1,0) наносит `share` (0,6) урона. Ракета 85 × 0,6 = 51 → 1500 / 51 ≈ 30 ракет,
   самонаводящаяся 48 → 32. Сообщению `Explosion` не нужен новый тип оружия (23 места создания).
4. **Лазер по танку — урон, равный остатку здоровья.** В `laser::apply_beams` у цели с `HeavyTank`
   от луча команды `Player` урон `max(health.current, shot.damage)`. Луч танков по танкам не меняется.

## Risks / Trade-offs

- Ракеты сильнее по танкам и чуть по площади вокруг поражённой цели — расход ракет растёт медленнее.
- Лазер с одного импульса снимает танк — танки перестают быть угрозой при лазере; лазер ограничен
  60 патронами и поднимается из ящиков.
