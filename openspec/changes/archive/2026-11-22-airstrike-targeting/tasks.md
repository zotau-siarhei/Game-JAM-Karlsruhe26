## 1. Режим наведения

- [x] 1.1 Ресурс `AirstrikeTargeting` в `airstrike.rs`: вход по выстрелу авиаударом вместо мгновенного вызова, плавный `blend` 0→1 за 0,3 с реального времени и обратно, предел 6 с с автоударом, закрытие без удара при гибели лунохода, потере фокуса и перестройке мира; проверка: тесты «вход не тратит заряд», «по истечении 6 с удар в текущей точке», `cargo build` — ресурс `airstrike::Targeting`, вход в `call_airstrike`, удар и отмена в `aim_strike`, переход по реальному времени в `blend_targeting`; при паузе, смене оружия, гибели и `WorldRebuilt` режим закрывается без удара; ECS-тестов нет
- [x] 1.2 Время: скорость `lerp(1, 0.2, blend)`, `impact::run_slowmo` не трогает время при открытом режиме; проверка: тест «взрыв в режиме не меняет скорость времени», `cargo build` — `blend_targeting` ставит скорость сглаженно, `impact::run_slowmo` пропускает кадры, пока `Targeting::active()`; курсор стика и камера в режиме идут по реальному времени; теста нет

## 2. Прицел и отметка

- [x] 2.1 Точка наведения из `AimPoint` с пределом 80 м; с геймпада в режиме правый стик сразу ведёт курсор без захвата врагов; проверка: `cargo build`, точка не уходит дальше 80 м — `aim::clamp_within` с дальностью 80 м в режиме; стик в режиме — курсор вдвое быстрее, без захвата
- [x] 2.2 Превью отметки: полупрозрачная полоса нужной длины (второй самолёт поперёк на 3-м уровне), красная при пересечении с луноходом; колесо мыши и бамперы поворачивают её шагом 15°, колесо в режиме не меняет оружие; проверка: снимок из игры, `cargo build` — превью пересоздаётся каждый кадр (`preview_strike`), колесо и бамперы/крестовина — `turns`, `arsenal::select_weapon` в режиме молчит
- [x] 2.3 Подтверждение левой кнопкой или R2 — прежний вызов по отметке режима, заряд тратится, клик не стреляет другим оружием; отмена правой кнопкой, Esc, B — без удара, Esc не ставит паузу; проверка: `cargo build`, вручную: подтверждение и отмена — B на геймпаде в забеге нажимает правую кнопку мыши; Esc в режиме не ставит паузу (`run::pause_on_escape_or_blur`)
