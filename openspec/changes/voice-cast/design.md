## Context

`voice-lines` дал `assets/voice/lines.json`, `src/voice.rs` и предпросмотр. `audio-minimap` описывает
голос штаба с тремя уровнями тона, отбор реплик без очереди и субтитры. Это изменение наполняет список содержанием
и добавляет голос лунохода. Код игры оно не меняет.

## Goals / Non-Goals

**Goals:**
- Тексты, тон и звучание всех реплик в одном файле, который читают игра, предпросмотр и генерация.
- Озвучка одной командой, с возможностью перегенерировать одну реплику.

**Non-Goals:**
- Очередь, приоритеты и субтитры в игре: это `audio-minimap`.
- Звуки оружия: это `weapon-meme-sounds`.

## Decisions

### Дополнительные поля прямо в `lines.json`
`speaker` (`dana` | `bolt`), `station`, `tone` (1 вежливо, 2 беспокойство, 3 паника), `delivery`
(указание по интонации для человека), `tts` (текст для синтеза с тегами вроде `[deadpan]`,
`[panicked]`), `effect`, `accent`, `pri`, `kind`. `serde` в `src/voice.rs` пропускает неизвестные
поля, поэтому игра работает без правок. Альтернатива — отдельный файл рядом: два списка
расходились бы.

### Варианты — отдельные id с суффиксом
`house_destroyed`, `house_destroyed_2`, `house_destroyed_t2`, `house_destroyed_t3`. Первые id
совпадают с заведёнными в `voice-lines`. Выбор варианта по поводу и тону делает игра позже.

### Голоса и станции — `voices.json`
DANA и станции лунохода: `action`, `trailer`, `scifi`, `arcade`, `mechanic`, `brainrot`, `doom`.
У каждого описание для ElevenLabs Voice Design, акцент и эффект. Писки и вопли лунохода — звуки
(`kind: sfx`), а не речь.

### Эффекты накладываются при генерации
`headset` (штаб: полоса 250–3800 Гц, компрессия), `radio` (луноход: полоса 400–3000 Гц, шипение
настройки перед фразой, лёгкий биткраш), `helmet`, `none`, суффикс `+bleep` добавляет 8-битный
бип-цензор в конец. Эффект запекается в файл, игре ничего делать не нужно. Исходники без эффекта
лежат в `assets/voice/raw/` и не коммитятся, эффект можно наложить заново командой `fx`.

### Скрипт на Python вместо `src/bin/gen_audio.rs`
`scripts/gen_voice.py` без зависимостей: не ждёт компиляции Bevy и запускается сразу. Утилита
из `audio-minimap` для звуков и музыки может прийти позже и читать тот же `lines.json`.

### Модель синтеза
`eleven_v3` понимает теги интонации в тексте. Если она недоступна, скрипт убирает теги и берёт
`eleven_multilingual_v2` с настройками голоса из `voices.json`.

## Risks / Trade-offs

- [Команда `design` и модель `eleven_v3` не проверены с настоящим ключом] → при ошибке голоса
  создаются вручную в Voice Design по описаниям из `voices.json`, id вписываются в файл.
- [Культовые цитаты дословно] → решение команды; озвучиваются своими голосами, без записей
  из фильмов и без имитации актёров.
- [Мемы приедаются] → правила редкости в `rover-radio`; список «не берём» в `meme-analysis.md`.
