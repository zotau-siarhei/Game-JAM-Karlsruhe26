# audio-assets Specification

## Purpose
Звуковые ресурсы игры: где лежат звуки и музыка, как они описаны и как создаются через ElevenLabs.
Реплики штаба уже устроены изменением `voice-lines`, звуки и музыка следуют тому же порядку.

## Requirements

### Requirement: Списки ресурсов
Звуковые эффекты SHALL описываться списком `assets/sfx/sounds.json`, музыка — списком
`assets/music/tracks.json`, в том же формате, что список реплик `assets/voice/lines.json`:
у каждой записи идентификатор, описание события, текст и имя файла. Для звуков и музыки
текст MUST быть описанием, по которому ресурс генерируется в ElevenLabs. Файлы SHALL лежать
в каталоге своего списка.

#### Scenario: Добавление звука
- **WHEN** в `sounds.json` добавлена запись, а рядом положен файл
- **THEN** звук доступен в игре по идентификатору без изменения кода

### Requirement: Генерация через ElevenLabs
Звуки, музыка и реплики SHALL генерироваться через ElevenLabs отдельной утилитой проекта
по этим трём спискам. Утилита MUST создавать только отсутствующие файлы и перегенерировать
существующий только по явной просьбе для конкретного идентификатора.

#### Scenario: Добавлена реплика
- **WHEN** разработчик добавил в `lines.json` новую реплику с текстом и запустил утилиту
- **THEN** утилита создаёт файл только для неё, остальные файлы не трогает

### Requirement: Ключ доступа
Ключ ElevenLabs SHALL браться из переменной окружения. Ключ MUST NOT попадать в репозиторий,
в файлы ресурсов и в сборку игры.

#### Scenario: Нет ключа
- **WHEN** утилита запущена без ключа
- **THEN** она завершается с понятным сообщением, какую переменную задать

### Requirement: Игра без сети
Игра SHALL проигрывать только готовые файлы из ресурсов проекта и MUST NOT обращаться к сети.
Отсутствующий файл или ошибка в списке MUST NOT ломать игру: соответствующий звук не звучит,
в лог пишется предупреждение.

#### Scenario: Запуск без интернета
- **WHEN** игра запущена на компьютере без сети
- **THEN** все звуки, музыка и реплики работают

#### Scenario: Файла нет
- **WHEN** одного звукового файла нет в ресурсах
- **THEN** игра запускается и работает, этот звук не звучит, в логе предупреждение

### Requirement: Ресурсы в репозитории
Списки и сгенерированные файлы SHALL храниться в репозитории, чтобы любой участник команды
собирал игру со звуком без доступа к ElevenLabs.

#### Scenario: Новый участник
- **WHEN** новый участник клонирует репозиторий и запускает игру
- **THEN** звук работает без генерации
