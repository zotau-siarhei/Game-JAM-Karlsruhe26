# Space Guard

Игра для [Game Jam Karlsruhe 2026](https://gamejam-karlsruhe.hackops.tech/): аркадный 3D-шутер с видом сверху. Луноход на холмистой планете отбивается от волн врагов и оружием перекраивает саму планету: взрывы оставляют кратеры, сносят дома и рвут железную дорогу. Жизнь одна, концовки нет, счёт — время выживания.

## Запуск

```sh
cargo run
```

Запускать из корня репозитория: игра берёт звуки и модели из `assets/`. Первая сборка Bevy занимает 10–20 минут, последующие — секунды. Ускорить пересборку во время разработки:

```sh
cargo run --features bevy/dynamic_linking
```

Сборка только нативная: macOS на Apple Silicon и Linux. Браузерной (WASM) сборки нет.

## Управление

| Действие | Клавиши |
|---|---|
| Ехать и поворачивать | W, A, S, D или стрелки |
| Прицел | мышь |
| Выстрел выбранным оружием | левая кнопка мыши |
| Выбор оружия | 1–6 или колесо мыши |
| Ремонт (луноход при этом едет медленнее) | удерживать пробел |
| Пауза | Esc |
| На паузе | Esc — продолжить, R — заново, M — в меню, Q — качество картинки |
| Меню | Enter, пробел или клик — начать забег, Esc — выход |
| Конец забега | ввести имя для таблицы рекордов, Enter — новый забег, Esc — в меню |

## Что уже есть

- **Планета**: бесконечный холмистый рельеф от сида, посёлки с домами и жителями, деревья и камни, железная дорога с поездами и туннелями.
- **Разрушения**: взрыв вырывает кратер, повторные взрывы его углубляют; дома рушатся, объекты разлетаются на обломки, пути рвутся, поезда сходят с рельсов. Под корой лава: глубокий кратер пробивает кору, и разливается озеро.
- **Оружие**: пулемёт, мортира, ракеты, самонаводящиеся ракеты, лазер, авиаудар. Пулемёт и мортира есть с начала забега, остальное и боеприпасы — в ящиках на парашютах и в трофеях с врагов. Аптечки и ремонт возвращают здоровье.
- **Враги**: таран-стрелок, мортирщик, ракетный и лазерный танки на общем шасси, перехватчик; приходят волнами, часть высаживается в десантных капсулах. Каждая четвёртая волна — босс «Колосс».
- **Экраны**: меню, пауза, конец забега с таблицей рекордов, которая сохраняется между запусками. Полоса здоровья, панель оружия, мини-карта, индикатор тревоги жителей.
- **Звук**: эффекты, музыка по ходу забега, голос штаба с субтитрами, комикс-надписи на выстрелах и взрывах.
- **Картинка**: HDR и свечение, три ступени качества.

- **Служба защиты жителей**: снос домов и гибель жителей поднимают тревогу; по её ступени приезжают спасательные машины, окружают луноход, стреляют и вывозят жителей, а при затишье уезжают.
- **Голос**: короткое интро штаба с пропуском и обучение голосом при первом появлении каждой механики.

Что ещё открыто по каждой механике — в `tasks.md` изменений (`openspec list`).

## Стек

- Rust 1.99: версия закреплена в `rust-toolchain.toml`, rustup поставит её сам.
- [Bevy](https://bevy.org) 0.20.1, частицы — `bevy_hanabi`, тряска камеры — `bevy_trauma_shake`.
- Целевое железо — MacBook Air M2.

На Linux Bevy нужны системные библиотеки `alsa-lib` и `libudev` ([список по дистрибутивам](https://github.com/bevyengine/bevy/blob/main/docs/linux_dependencies.md)).

Звуки, музыку и реплики генерируют через ElevenLabs скрипты `scripts/gen_audio.py` и `scripts/gen_voice.py`; ключ — в переменной окружения `ELEVENLABS_API_KEY`. Игре сеть не нужна.

## Документы

- `docs/requirements.md` — требования к игре и приоритеты.
- `CLAUDE.md` — где что лежит в коде и правила проекта.
- `openspec/` — требования, нарезанные на изменения [OpenSpec](https://github.com/Fission-AI/OpenSpec): контекст в `openspec/config.yaml`, изменения в работе в `openspec/changes/`, принятые спецификации в `openspec/specs/`.

Команды OpenSpec:

- `/opsx:propose "идея"` в Claude Code — предложить изменение;
- `/opsx:apply` — реализовать его;
- `/opsx:archive` — перенести принятое изменение в спецификации;
- `openspec list`, `openspec validate --all` — посмотреть изменения и проверить артефакты.
