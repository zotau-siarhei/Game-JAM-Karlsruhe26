# Починка моделей Meshy

Типовые огрехи моделей из Meshy и скрипты, которыми они исправлены (2026-11-15, Sergei Zotov).
Скрипты Blender запускаются как `/Applications/Blender.app/Contents/MacOS/Blender -b --python <скрипт> -- <аргументы>`.

| Огрех | Как выглядит | Скрипт |
|---|---|---|
| Светлый фон картинки-образца запечён в текстуру листвы | белёсые кончики веток, «снег» на ели | `foliage_texture.py` (по PNG из glb), затем `glb_swap_image.py` |
| Нормали усреднены через тонкие листовые пластины | листья мигают светом и тенью при повороте | `normals.py` |
| Почти совпадающие грани | мерцание при неудачной точности глубины | `overlaps.py` |
| Открытый шов по протектору колеса | две дыры, сквозь них виден диск | `wheel_seam.py` |
| Дубли граней и нормали, усреднённые через несвязанные куски (дома) | плоскости крыши и стен мерцают, на скате вспыхивает треугольник | `stacked_faces.py` |
| Ключи поворота кисти развёрнуты на 150–180° от позы покоя | ладонь загнута к предплечью | `straight_hands.py` (Python без Blender) |
| Кости пальцев ни к чему не прикреплены | пальцы висят на месте, ладонь уходит | `reparent_bones.py` (`Кость=Новый_родитель`) |
| Дырка в плоской стене без открытого края | треугольная дыра во фронтоне | `patch_hole.py` (заплатка цвета стены) |
| Текстуры JPEG и 2K | Bevy собран без JPEG — модель не грузится, остаётся запасной облик | `textures_png.py` (1024, PNG) |

Что прогнано:

- `tree_spruce`, `tree_poplar`: `foliage_texture.py` → `glb_swap_image.py`;
- `tree_oak`, `tree_pine`: то же, затем `normals.py`;
- `bush`: то же, затем `overlaps.py` и `normals.py`;
- `enemy_wheel`: `wheel_seam.py`;
- `house_small`, `house_two_story`, `house_barrack`: `stacked_faces.py`, у `house_small` затем `patch_hole.py -- … -1 -0.15 0.15 0.16 0.36`, у всех `textures_png.py`;
- `enemy_rocket_robot`: перепривязка костей пальцев к кистям, затем `straight_hands.py`.

Картинку из glb достать так: в бинарном куске glb — `images[0].bufferView`, сохранить байты как PNG.
Размеры и положение моделей не меняются, `models.json` править не нужно.
Текстуры в `assets/models` — только PNG: Bevy в игре собран без поддержки JPEG.
